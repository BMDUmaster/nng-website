## View the exact existing build first

Requires Node.js 20.9 or newer. This preview needs **no package installation**:

```sh
npm run verify:published
npm run preview
```

Open **http://127.0.0.1:3448/NNG_Codex_Build/preview-20261004-r1/**.

The original folder structure is intentional: generated asset and navigation URLs contain `/NNG_Codex_Build/preview-20261004-r1`. Opening an HTML file directly or serving the inner folder as `/` will break those URLs. The bundled server handles this correctly, including video byte ranges.

## Edit the main website

```sh
npm ci
npm run dev
```

Open http://localhost:3400/. The editable code is at the repository root, not inside `published/`. Do not modify the preserved snapshot to make source changes.

Useful entry points:

- `src/app/page.tsx`: homepage.
- `src/content/site.ts`: identity, public enquiry contacts and navigation.
- `src/content/review-release.ts`: review consultation labels and provisional scopes.
- `src/components/offerings/ReviewServicePage.tsx`: current Psychic Reader/Vastu treatment.
- `src/content/offerings/pages/`: individual service copy; registry generated by `npm run build:pages`.
- `src/content/stone-articles.ts` and `src/content/blogs.ts`: educational demo articles and blog index; templates are under `src/app`.
- `src/content/shop/catalogue.json`: current public catalogue.
- `src/content/consultation.ts`: pending public fee settings. Historic unpublished prices are not included.

No Laravel runtime is needed to run this current static/Next website. The older PHP adapter and its stale generated views are not the source of the public preview and are not used here.

## Rebuild the whole review site

```sh
npm run build:review
npm run preview:rebuilt
```

This builds the main static export **and** the five landing pages, then assembles them at `dist-review/NNG_Codex_Build/preview-20261004-r1/`. It does **not** overwrite `published/`, push to GitHub, or deploy anything.

The command preserves the existing staging URL/base path, noindex setting and public business enquiry number. A Next.js rebuild may produce different build IDs, chunk hashes and sitemap dates; that is why an exact original snapshot is included separately. For a new deployment URL, change `scripts/build-review.mjs` and the canonical base in `landing-pages/build-review-v2.mjs` deliberately, then check all links and media again.

Developer checks:

```sh
npm run typecheck
npm run lint
npm run check:routes
```

`check:routes` checks generated exports, so run `build:review` first. The existing editorial copy-lint is also preserved but is not a substitute for client content approval.

## Review status and privacy boundaries

This is a **public developer handoff of the staging build**, not production approval, a booking system launch or an ad launch. Existing review copy and demo blogs remain as published. Fees, detailed scope/format/duration, report terms, some Vastu distinctions and final sign-off still need confirmation. WhatsApp links prepare a message for the visitor to send; there is no payment checkout or home-video upload collector.

The repository retains every file in the public snapshot. It intentionally excludes credentials, private environment files, historical unpublished prices, private client-name checks, private supplier-review documents, internal research/audit conversations, the unpublished book PDF, dependencies and temporary build caches. The original local sources and the existing public preview remain untouched.

See `handoff/HANDOFF.md` for provenance and the verification record.
